# درخت توت — وب‌گاه روستا

وب‌گاه معرفی روستای درخت توت: صفحه‌ی اصلی، شجره‌نامه‌ی سه‌بعدی، بزرگان، اخبار و صفحه‌ی ۴۰۴.

**نمایش زنده:** https://soheilja.github.io/derakht-tot

## اجرا در محیط لوکال

```bash
npm install
npm run dev
```

سپس با یک سرور لوکال (مثلاً `python -m http.server`) پروژه را روی http://localhost:8000 باز کنید.

> صفحه‌ها را مستقیماً با دابل‌کلیک روی فایل باز نکنید؛ ماژول‌های ES روی پروتکل `file://` به‌خاطر CORS کار نمی‌کنند.

## ساختار پروژه

- `index.html` — صفحه‌ی اصلی (معرفی، گالری، تاریخچه، سنت‌ها، اخبار، تماس)
- `family-tree.html` — شجره‌نامه‌ی سه‌بعدی (Three.js)
- `elders.html` / `elder.html` — فهرست و صفحه‌ی بزرگان
- `news.html` / `news-detail.html` — فهرست و صفحه‌ی اخبار
- `404.html` — صفحه‌ی خطا
- `css/input.css` — استایل‌ها و تم رنگی پروژه (Tailwind v4)؛ خروجی نهایی `css/output.css`
- `js/` — اسکریپت‌های صفحه‌ها
- `js/data/` — داده‌های موک روستا (بزرگان، اخبار، شجره‌نامه)

## ویرایش استایل‌ها

فقط `css/input.css` را ویرایش کنید. این فایل شامل تم رنگی و تمام استایل‌های سفارشی است و با دستور `npm run dev` به‌صورت خودکار به `css/output.css` بیلد می‌شود. ویرایش سایر فایل‌های CSS اثری ندارد.
